# Claude（協調者）的分工提案

| 成員 | 調查階段 | Demo 階段 |
|---|---|---|
| **Gemini** | 競品網站調查：10–15 個遊戲／文化敘事遊戲網站（如《返校》赤燭、《Spiritfarer》、《Florence》、《Never Alone》、《Gris》、《Before Your Eyes》、大學或博物館做的文化遺產遊戲），整理每個網站的頁面架構、首屏放什麼、內容類型、行動呼籲（CTA）、它們怎麼經營「影響力」。產出比較表 + 可借鏡的模式 | 做方向 A 的 demo |
| **Codex** | 我們網站的內容與結構健檢：逐段判斷該留／該刪／該升級為重點／該降級；資訊架構、首屏訊息、CTA 路徑、SEO／分享卡、手機版、載入效能、無障礙 | 做方向 B 的 demo |
| **Claude** | 受眾與影響力分析：誰會來看（玩家、政大師生校友、評審、合作單位、媒體、在地社區），各自要什麼；研究「有社會影響力的專案網站」（非遊戲）的做法；統整兩份調查，寫企劃書（≥3 個方向 + 後續效益） | 做方向 C 的 demo，並統整三個 demo |

流程：分工定案 → 平行調查 → Claude 統整並提出 3 個方向 → 三家各做一個 demo → Claude 交出企劃書。
