## 一、一頁摘要

**問題**：現在的網站是一份完成度不錯的「歷年記」，主詞是「我們做了什麼」。它把最有影響力的三件事——**永安的真實地景與人**、**兩款現在就能玩的作品**、**政大百年的時間窗**——跟競賽影片、支線任務排成同樣的份量。訪客看完不知道該先玩哪一款，也不知道怎麼合作。（Codex 健檢、Gemini 對標、Claude 受眾分析三方一致）

**三個方向**：

| | 方向 A：《沉村》敘事旗艦站 | 方向 B：政大百年數位門面 | 方向 C：記憶保存工作室 |
|---|---|---|---|
| 一句話 | 水面之下，有一座村莊。 | 政大一百歲，走進來，留下你的故事。 | 把即將消失的地方，變成可以玩的世界。 |
| 主角 | 《沉村之歌》與永安的人 | 3D 政大與校友 | 方法論、成果數據、合作方案 |
| 最想打動 | 大眾、玩家、媒體 | 政大校方、校友、師生 | 合作決策者、評審、其他 USR 與地方政府 |
| 網站要人做的事 | 潛入遊戲、分享 | 走進 3D 政大、投稿故事、校方洽談 | 寄出合作信、下載 Press Kit |

## 三、調查結論：哪些該放、哪些不該放、哪些才是重點

### 3.1 好網站反覆出現的模式（Gemini 對標 15 站歸納，Claude 篩選）
1. **首屏 = 沉浸主視覺 + 一句話高概念 + 雙軌按鈕**（主按鈕「玩」，次按鈕「了解／合作」）。沒有一個標竿網站在首屏放「版本演進」。
2. **把田野變成展品**：Never Alone 把與阿拉斯加原住民社群（耆老、說書人與社區成員，近 40 位）合作拍的訪談短片做成「Cultural Insights」，在遊戲中解鎖，是它最大的賣點。蓋亞造界的耆老訪談、《永安的記憶》小冊、實景照片，正是同一種資產。
3. **對照比文字有力**：實景 vs 遊戲、2D vs 3D 用拖曳滑桿呈現，不用形容詞。
4. **用空間取代時間軸**：政大 → 深坑 → 永安是一條真實的地理路線，比「2025.05、2026.04」更好記。
5. **影響力要量化**，而且要有統計口徑。
6. **有專門給教育者／合作方／媒體的入口**（Walden 的 Educators 專區、Charles Games 的委託合作、Press Kit）。

### 3.2 現站逐段判斷（Codex 健檢）

| 升級為重點 | 保留但精簡 | 降級或合併 | 該刪或改寫 |
|---|---|---|---|
| 首屏（改成體驗與使命） | CH01 像素政大（交代起點即可） | 數字列（2027 是計畫不是成果） | `Andy [角色]` 佔位文字 |
| PROLOGUE 的使命句 | CH02 深坑（三張相近截圖選一張） | 版本演進導覽（改放後段） | 「隊名：金牌特攻隊」這類報名表語氣（Gemini） |
| CH03 永安「實景 × 遊戲」 | NEXT 百年計畫（等合作具體再升級） | 支線任務 LINE 與《薪火》（收進「其他實踐」） | 首屏圖 `title-3d-b.jpg`：圖裡有假按鈕，會讓人以為能點 |
| CH04《沉村之歌》 | BEFORE/AFTER（考慮換成永安對照） | 「報導」區（itch.io 和 USR PDF 不是報導） | 「4 項競賽肯定」：把「競賽獎項」和「經費支持」分開 |
| CH05 3D 政大（但要寫清楚現在是什麼版本） | 獲獎（當信任證據，不必大篇幅） | 首頁 5 支 YouTube 只留 1 支 | |
| 結尾聯絡（改成「玩家」「合作方」兩條路） | 團隊（游泳隊起源很有記憶點） | | |

### 3.3 受眾主次（Claude）
1. 合作決策者（百年計畫、USR 辦公室、在地社區、企業 ESG）——槓桿最大
2. 評審與獎助單位
3. 媒體與策展人
4. 玩家（政大師生校友、對台灣文化有興趣的人）
5. 在地長輩與社區——作品正當性的來源
6. 未來隊員

**原則：情感是入口，合作是出口。** 首屏用大眾也會被打動的故事吸人，但第二個按鈕一定要給合作方。

### 3.4 現站最缺的兩樣東西
- **數字**：訪談了幾位長輩？幾小時口述？多少人玩過？網站一個都沒有。
- **下一步**：合作只有兩個學號信箱，沒有「可以合作什麼」。

## 四、三個提案方向

### 方向 A：《沉村》敘事旗艦站——讓網站本身就是一段潛水
**[開啟 demo-A](03-demo/demo-A-沉村敘事.html)**（Codex 製作）

- **概念**：首頁是一段捲動式敘事。往下捲就是往水底潛：水面 → 1987 → 實景／遊戲拖曳對照 → 長輩語錄 + AI 村民試聊（示意）→「潛入完整遊戲」。深坑、3D 政大收進「更多世界」。
- **網站架構**：首頁（沉村敘事）／更多世界（深坑、3D 政大、像素政大）／關於團隊／Press
- **該放**：underwater.jpg 當主視覺、永安實景 × 遊戲對照、長輩語錄（需授權）、AI 村民的互動預覽、單一主要按鈕
- **不放**：版本時間線、競賽影片、LINE 支線（全部移到次頁）
- **影響力目標（可量測）**：itch.io 瀏覽與遊玩數、從網站點進 itch.io 的比例、社群分享數、媒體與策展邀約數
- **後續效益**
  - 短期（3 個月）：網站有一個能被轉傳的故事，讓媒體、策展人、文化類評審 30 秒內懂；直接帶 itch.io 流量
  - 中期（到 2027）：成為文化類獎項、影展、獨立遊戲展的投件素材；累積玩家數，作為其他合作的證據
  - 長期：建立「蓋亞造界 = 會說故事的團隊」的品牌，像 Never Alone 那樣讓田野成為作品的賣點
- **成本**：中。主要是內容，不是技術——長輩語錄與照片授權、主敘事句的史實核對、手機上的捲動效能
- **風險**（Codex、Gemini）：越沉浸，史實錯了越容易誤導；政大百年與深坑被壓成配角，校方或外校 USR 進來可能以為只是單一專案

### 方向 B：政大百年數位門面——每個校友心中都有一座四維堂
**[開啟 demo-B](03-demo/demo-B-政大百年.html)**（Claude 製作）

- **概念**：首頁是 3D 政大入口，依身份分三條路（校友／師生／學校單位）。核心是**百年故事地圖**：校友投稿的故事會被放回 3D 校園裡發生的地點。另有實體導覽路線、包種茶節，以及給百年計畫的三個合作方案和時程。地方作品變成「政大走出校門的那一章」。
- **網站架構**：首頁（3D 政大＋三條路）／百年故事地圖／投稿／線下活動／我們走過的地方／百年合作提案
- **該放**：plaza-3d.jpg 當主視覺、2D/3D 四維堂對照滑桿、故事地圖、投稿表單、合作時程
- **不放**：ESG 碳數據、競賽細節
- **影響力目標**：投稿故事數、3D 政大造訪數、實體導覽走過人數、與校方簽下的合作項目數
- **後續效益**
  - 短期：一個能直接拿去跟百年計畫、秘書處、校友中心談的提案頁，比口頭說明有力
  - 中期（到 2027）：若被納入百年活動，等於拿到全校師生與校友的曝光、官方背書，可能還有經費（百年政大薈萃基金的用途之一就是四維堂修繕，與 3D 四維堂天然相關）
  - 長期：百年過後，3D 政大可轉成新生導覽、招生工具，持續有人用
- **成本**：中到高。投稿要後台、審核、個資與授權說明；3D 場景要持續放入故事
- **風險**：高度依賴校方是否合作；投稿少時地圖會很空；政大色彩太重，外部單位難以想像能複製到別處

### 方向 C：GaiaCraft 記憶保存工作室——把即將消失的地方，變成可以玩的世界
**[開啟 demo-C](03-demo/demo-C-記憶工作室.html)**（Gemini 製作）

- **概念**：把團隊定位成一個「方法」，而不只是一款遊戲。首頁 = 使命 → 影響力儀表板 → 三步轉譯方法（田野與口述 → AI 記憶轉譯 → 會記得你的 NPC）→ 三個場域案例切換 → 依身份切換的合作通道（大學 USR／地方政府與社區／企業 ESG 與教育）→ Press Kit。
- **網站架構**：首頁／方法／案例（永安、深坑、政大）／合作（三條通道）／Press Kit
- **該放**：影響力數字（要先建立統計口徑）、方法圖解、田野照片、正確區分的獎項與經費支持、事實表
- **不放**：長篇開發日記、太多遊戲細節
- **影響力目標**：合作詢問信數（依通道分）、Press Kit 下載數、獲得的補助與委託案數
- **後續效益**（Gemini 撰寫，Claude 校訂）
  - 短期：成為「不用再解釋」的提案工具，可直接用於年底到明年初的補助申請、校內跨處室溝通
  - 中期（到 2027）：以永安＋政大兩個案例做成「校園 × 地方記憶轉譯」範本，吸引外校 USR、地方文化單位主動來詢問
  - 長期：從「靠獎金養作品」走向「有委託案源的文化科技團隊」，類似從大學衍生出來的 Charles Games
- **成本**：中。技術不難，難在數字——要回頭整理訪談人數、口述時數、玩家數
- **風險**（Gemini 自己點出）：最容易做成冰冷的接案公司官網，把長輩的故事稀釋成 KPI；（Codex）數字口徑沒建立就上儀表板，反而傷害可信度

## 六、三方共同推薦：A + C 雙層主站，B 做成百年專頁

**主站**：首屏和前半段用 A 的潛水敘事抓住人（情感），後半段自然接到 C 的方法、數字、合作通道和 Press Kit（信任與行動）。
**百年專頁**：B 做成 `/nccu100`，等校方合作確定、投稿機制備妥再上線，主站首屏放一個入口。

| 誰說的 | 說法 |
|---|---|
| Codex | 「用《沉村》讓人理解作品，再用方法、證據與合作入口回答『為何找你們』。B 保留為百年校慶專頁。」 |
| Gemini | 「A 和 C 是表與裡：沒有 A 的情感衝擊，C 的方法論沒有說服力；沒有 C 的架構，A 無法變現與擴展。」 |
| Claude | 同意。補充：B 有 2027 截止日，建議**現在就先用 demo-B 去跟百年計畫談**，談成了再投入開發，不要先做完才去談。 |

**建議時程**
1. **現在 – 1 個月**：做第七節的「共同基礎」；整理數字與授權；拿 demo-B 去約百年計畫
2. **1 – 3 個月**：上線 A + C 主站
3. **校方確認後**：開發 B 百年專頁與投稿機制，2027 校慶前上線
