# 三個方向草案（Claude 統整三份調查後提出）

三份調查的共同結論：
- 現站是「以團隊為主詞的版本履歷」，最強的三項資產（永安實景×遊戲、兩款可玩作品、政大百年場景）被排成同等權重。（Codex）
- 好網站首屏 = 沉浸主視覺 + 一句話高概念 + 雙軌 CTA（玩 / 合作）；把田野變成展品；用空間取代時間軸；影響力要量化；要有 Press Kit 與合作通道。（Gemini）
- 受眾第一順位是合作決策者，但情感入口是玩家／大眾；最缺的是「數字」與「下一步」。（Claude）

---

## 方向 A：《沉村》敘事旗艦站——「讓網站本身就是一段潛水」
- **一句話**：你喝的每一口水底下，都有一座村莊。（史實與用語待團隊確認）
- **主角**：《沉村之歌》與永安的人
- **長相**：首頁就是一段捲動式敘事，往下捲＝往水底潛。依序看到：水庫水面 → 1987 年 → 實景／遊戲拖曳對照 → 長輩語錄 + AI 村民試聊預覽 → 「潛入完整遊戲」按鈕。其他作品收進次頁「更多世界」。
- **主要受眾**：大眾、玩家、媒體、文化類評審
- **對標**：Never Alone（Cultural Insights）、Spiritfarer（一句話高概念）、中研院開放博物館（對照滑桿）

## 方向 B：政大百年數位門面——「每個校友心中都有一座四維堂」
- **一句話**：政大一百歲，走進來，留下你的故事。
- **主角**：3D 政大百年慶版
- **長相**：首頁 = 3D 政大入口 + 「同一座四維堂，兩個世代」對照 + 百年故事徵集（校友投稿，故事會被放進 3D 校園的地點）+ 實體導覽路線、包種茶節活動 + 給校方的合作提案頁。地方作品是「政大走出校園」的一章。
- **主要受眾**：政大校方（百年辦公室、秘書處）、校友、師生
- **對標**：Ubisoft Discovery Tour（可走進去的博物館）、數位島嶼（記憶徵集）、暨大（線上 → 線下活動閉環）

## 方向 C：GaiaCraft 記憶保存工作室——「把即將消失的地方，變成可以玩的世界」
- **一句話**：我們把耆老的記憶變成會記得你的 NPC。這套方法，可以帶到你的社區。
- **主角**：方法論 + 影響力數據 + 合作方案
- **長相**：首頁 = 使命 + 三步驟方法（田野 → AI 轉譯 → 可玩世界）+ 三個案例（政大／深坑／永安）+ 影響力儀表板（耆老人數、口述時數、玩家數、場域數、獎項）+ 三條合作通道（大學 USR／地方政府與社區／企業 ESG 與教育）+ Press Kit。
- **主要受眾**：合作決策者、評審與獎助單位、其他大學 USR、地方政府
- **對標**：Attentat 1942 / Charles Games（大學衍生團隊 + 委託合作）、Walden（Educators 專區）、教育部 USR EXPO（影響力儀表板）
