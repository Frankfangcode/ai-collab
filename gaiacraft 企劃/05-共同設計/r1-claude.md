# Claude 第 1 輪提案：一支游泳隊的潛水冒險

## 1. 核心概念
**一句話**：一支政大游泳隊，潛進了被水淹沒的村莊。
**貫穿全站的隱喻：「下潛」**。整個網站是一次潛水，往下捲就是往下潛：從政大的泳池出發 → 經過深坑老街 → 潛入翡翠水庫底的永安 → 在水底聽見長輩的故事 → 浮上水面，帶著記憶回到政大。

為什麼只有蓋亞造界能用：**團隊是游泳隊，作品裡有一座真的沉在水底的村莊**。這個巧合是真的，別的團隊借不走。它同時解決兩件事：游泳隊起源不再只是一句冷知識，而是整個敘事的動機；「潛水」也天然就是一條從水面到深處的捲動結構。

## 3. 視覺系統
- **顏色全部從截圖取**：
  - 泳池／水面：#CBE0AD、#87B174（plaza 的淺綠）過渡到 #69928D
  - 水底：#17262D、#2B4143、#46625F（灰綠，不要深藍）
  - 深坑紅磚：#9F6E56、#5B443F
  - 紙張（委託單、收集冊）：#F6F1DF
  - 強調色只用一個：#BF9B61（campus 裡的土黃），當按鈕與水深計
- **字體**：標題、按鈕、水深計、對話框用 Cubic 11 像素字；內文一律 Noto Sans TC 16–18px，**長段落絕不用像素字**。
- **像素元素**：對話框邊框、按鈕、水深計、收集冊格子、角色卡。照片和截圖保持原樣，不加像素濾鏡。
- **動效**：只有三種——逐字打出、水深計數字跳動、入水那一條線。其餘都靜止。全部遵守 prefers-reduced-motion。

## 4. 文案語氣
- 首屏：「一支游泳隊，潛進了被水淹沒的村莊。」
- 合作區：「有委託嗎？我們接任務。」
- NPC（示意）：「你是從政大來的？……以前這裡種茶。〔待填：經授權的長輩說法〕」
- **原則**：像學生在跟你聊天，不是顧問在提案。句子短。事實就寫事實，不寫排比。可以有一點遊戲的幽默，但碰到長輩和沉村時要收斂、要尊重。

## 5. 我最堅持 / 最不確定
- **最堅持**：「游泳隊 × 沉村 × 下潛」這個隱喻。它是唯一一個別人借不走的概念。
- **最不確定**：整頁都走潛水，會不會讓「政大百年」被壓成開頭一小段？B 方向的校友投稿要放在哪？可能要在浮上水面（第 7 段）時做一個「回到政大」的大段落。
