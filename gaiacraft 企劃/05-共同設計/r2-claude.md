# Claude 第 2 輪：切磋

## 1. 採納
**從 Codex 採納**
- **首屏放永安實景與遊戲同框，取代 PRESS START 標題畫面**。我原本用 PRESS START 開場，但那是「形式」；Codex 的同框是「證據」。第一眼就看到一面真實的牆變成遊戲裡的牆，比任何標題都有說服力。我改成：同框照片是首屏主視覺，PRESS START 變成首屏上的按鈕文字。
- **手機上用「看實景／看遊戲」切換按鈕，不要只靠拖曳**。拖曳滑桿在手機上很難操作，這是我沒想到的實作細節。
- **「不代替居民發言」寫成原則**。NPC 改為「導覽 NPC」，是隊員角色在帶路，不是假扮長輩。
- **有人臉的田野照片在授權前不刊出**。

**從 Gemini 採納**
- **「下潛 → 浮出水面回到政大百年」的完整弧線**。這正好回答我自己最不確定的問題：政大百年不是開頭一小段，而是**浮上水面後的大結局**。這也是 Gemini 與我獨立想到同一個隱喻之後，它補上的另一半。
- **收集冊的「已解鎖」與「未解鎖虛線格」**，而且把《永安的記憶》小冊、商學院 LINE 排行榜放進已解鎖，比我原本只放「茶產業、魔神仔」這些主題更具體。
- **合作入口用 mailto 預填主旨**，兩個信箱都放。
- **4px 階梯狀像素邊框取代大圓角**。

## 2. 反對
- **反對 Gemini 的首屏文案**：「2025 年從政大游泳隊出發，我們把深坑老街、翡翠水庫底的永安村，還有即將滿百歲的政大，做成可以走進去說話的遊戲。」這句太長（55 字），首屏讀不完。替代：主標保持短句，長句降為副標。
- **反對 Gemini 的 NPC 示範句**：那是它自己寫的長輩語錄，即使加了引號也像是真的。替代：導覽 NPC 只說網站已公開、可查證的事（例如 Codex 那句「村口那面『失落村莊美景』的牆，照片和遊戲裡都有」）；真的長輩語錄只放在獨立的「語錄卡」，標示〔待填：經授權〕。
- **反對水深計用 -45m、+28m 這種數字**：沒有出處。替代：用**章節刻度**，例如「水面」「村口」「廟前」「水底」，不寫公尺；若之後查到翡翠水庫的正式水位資料再補上數字。
- **部分保留 Codex 的「記憶接力」**：接力很好，但它跟游泳隊的關聯要靠解釋，「潛水」不用解釋。我建議「接力」留給**結尾的合作區**：「下一棒交給你」，用接力棒的意象邀請合作，而不當全站主隱喻。

## 3. 回答別人的問題
- **Codex 問合作入口**：同頁展開。單檔好維護，而且合作方是看完整個故事才走到這裡，不該在最後一步再跳頁。三張委託單點開後在原地展開。
- **Gemini 問明暗順序**：**淺 → 深 → 淺**。理由是它和故事一致（政大泳池 → 潛入永安 → 浮出回到政大），而且最後的合作區要好讀，必須是淺底。至於首屏：首屏是 Codex 的「實景 × 遊戲同框」，本來就是彩色照片，不需要靠深色製造衝擊。

## 4. 事實問題的表態
- **NPC**：分成兩種角色。「導覽員」是隊員的像素化身，只說公開事實；「長輩語錄卡」只放經授權的原話，沒有就寫〔待填〕。網站上不能有任何看起來像長輩說的、卻是我們寫的句子。
- **水深計**：不用公尺，改用章節名稱當刻度。

## 5. 修正後的立場
- **核心隱喻**：一支游泳隊潛進沉村，再浮上水面回到百歲的政大；結尾把接力棒交給你。
- **首屏**：永安村口實景 × 遊戲同框（Codex），主標「一支游泳隊，潛進了被水淹沒的村莊」，兩個按鈕「▶ PRESS START」（玩）、「✉ 組隊合作」。
- **段落順序**：首屏同框 → THE PARTY 游泳隊 → 深坑 → 入水 → 永安水底（導覽 NPC＋語錄卡）→ 浮出水面・政大百年（四維堂對照＋校友故事）→ 收集冊 → 選一個世界去玩 → 接力：合作委託＋Press Kit。
