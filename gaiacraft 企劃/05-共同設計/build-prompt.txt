# 第 3 輪：設計決議（Claude 統整，標明每條出處）

## 核心
**隱喻**：一支政大游泳隊，潛進被水淹沒的村莊，再浮上水面，回到百歲的政大；最後把接力棒交給你。
- 「游泳隊 × 下潛」：Claude 與 Gemini 第 1 輪**各自獨立**提出
- 「浮出水面回到政大百年」當結局：Gemini
- 「接力棒交給你」用在合作區：Claude（取自 Codex 的「記憶接力」）
- 「下潛只用來串段落，不讓每一段都背水深設定」：Codex

**主標**：一支游泳隊，潛進了被水淹沒的村莊。（Claude；Gemini 的長句降為副標，Claude 建議）

## 視覺系統
- **明暗**：淺 → 深 → 淺。首屏與岸上用暖綠／紙色；入水後 #17262D 系灰綠；浮出後回到 #F6F1DF。（三家一致）
- **色票**（全部來自截圖取色）
  - 紙色 #F6F1DF、墨色 #17262D
  - 水底 #17262D / #2B4143 / #46625F / #69928D
  - 村莊與校園綠 #306822 / #2A541F / #87B174
  - 深坑磚 #9F6E56 / #5B443F
  - 唯一強調色 #BF9B61（Claude；Gemini 稱「包種茶湯暖金」）
- **字體**：Cubic 11 只用在章名、按鈕、旅程標記、對話框、收集冊格子；長文一律 Noto Sans TC。（三家一致）
- **像素元素**：4px 階梯狀邊框（Gemini），只框「遊戲裡的選擇」，不包住整篇文章（Codex）。照片不加像素濾鏡（Claude）。
- **禁用**：大圓角、毛玻璃、深海藍＋香檳金、描邊大年份、全大寫英文 kicker、三欄 01/02/03 卡。
- **動效**：只有逐字打出＋▼、旅程標記切換、入水線、對照切換；prefers-reduced-motion 時全部關閉。（三家一致）

## 文案原則
- 像隊員帶人看作品：講地點、做法、下一步。短句，不排比，不顧問腔。（Codex「隊員帶人看」＋Gemini「田野筆記 × 任務日誌」＋Claude「學生在聊天」）
- **事實界線**：網站上不能出現任何看起來像長輩說的、但其實是我們寫的句子。導覽 NPC 標「團隊導覽」，只說現站已公開的事。（三家一致）
- 協調者註記：Gemini 第 2 輪示範句中的「四條記憶支線」沒有出處，不採用。

技術要求：
- 建立單一檔案 ./gaiacraft-共同版.html（目前工作目錄），CSS/JS 內嵌、不用框架。不要修改其他任何檔案。
- 圖片路徑：../../gaiacraft 網頁/img/<檔名>（本檔在 gaiacraft 企劃/05-共同設計/ 底下）。大圖 loading="lazy"，首屏圖除外。
- 字型：@font-face 載入 Cubic 11（https://cdn.jsdelivr.net/gh/ACh-K/Cubic-11@main/fonts/web/Cubic_11.woff2，font-display: swap）；內文 Noto Sans TC（Google Fonts）。
- 像素邊框用 box-shadow 階梯做法；像素字只用在章名、按鈕、旅程標記、對話框、收集冊格子。
- 側邊旅程標記：桌機固定在左或右側，手機改成頂部細條；用 IntersectionObserver 切換目前階段。
- 對照：桌機可拖曳（range input，可鍵盤操作），手機（<720px）顯示「看實景／看遊戲」按鈕切換。
- 導覽 NPC 對話框：逐字打出＋閃爍 ▼，點擊或 Enter 下一句；標「團隊導覽」；內容只能用網站內容摘錄裡已公開的事實。另有一張「長輩語錄卡」只寫〔待填：經受訪者授權的原話〕。
- 《薪火》YouTube 用封面圖＋點擊才載入 iframe（https://www.youtube-nocookie.com/embed/t5pAcjZBMBA），封面可用 https://i.ytimg.com/vi/t5pAcjZBMBA/hqdefault.jpg。
- 合作區三種情境用可存取的 tab（role=tablist），每個情境：可一起做的事（取自現站：包種茶節、校園導覽、LINE 永續驗證、耆老訪談轉遊戲等）＋ mailto 預填主旨（兩個信箱：113306052@g.nccu.edu.tw、113506052@g.nccu.edu.tw）。
- Press Kit：一屏讀完的事實表（團隊、作品、平台、上架時間 2026.09 itch.io、獎項 3 項、經費支持 1 項、聯絡）。
- prefers-reduced-motion：關閉逐字、入水線動畫、平滑捲動。
- 375px 手機不可左右溢出；有 <main>、可見的 :focus-visible、skip link。
- 頁首一條小橫幅：「三家共同版・Claude × Codex × Gemini｜示意稿，非正式網站」。
- 頁尾放一段「這個版本怎麼來的」：簡列三家各貢獻了哪些想法（依決議的出處欄）。
